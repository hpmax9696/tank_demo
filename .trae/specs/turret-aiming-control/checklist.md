# Checklist

- [x] WASD 驾驶：W 键使坦克前进，S 键使坦克后退
- [x] WASD 驾驶：A 键原地左转（不按 W/S 时），D 键原地右转
- [x] WASD 驾驶：W+A 前进左转，W+D 前进右转，S+A 后退左转，S+D 后退右转
- [x] WASD 驾驶：松开所有键后坦克惯性滑行减速至停止
- [x] ↑/↓ 键不再影响履带移动
- [x] 鼠标指针在游戏中隐藏，显示自定义十字准星
- [x] 移动鼠标时炮塔旋转追踪瞄准点（有延迟，非瞬移）
- [x] 移动鼠标时炮管俯仰追踪瞄准点高度（有延迟，非瞬移）
- [x] 炮塔旋转范围 ±180°（相对车头方向）
- [x] 炮管俯仰范围 -10° 到 +25°
- [x] 瞄准点在射程内、无遮挡、角度可达时 → 准星绿色
- [x] 瞄准点超出射程/有遮挡/角度不可达时 → 准星红色
- [x] 鼠标左键主炮射击，炮弹沿炮管实际方向飞出
- [x] 手柄 RT 主炮射击
- [x] Space 键暂不绑定功能（预留同轴机枪）
- [x] 手柄 LT 暂不绑定功能（预留同轴机枪）
- [x] 手柄左摇杆控制驾驶（Y=前后，X=转向）
- [x] 手柄右摇杆 X轴控制炮塔旋转（摇杆幅度 → 旋转速度）
- [x] 手柄右摇杆 Y轴控制炮管俯仰，到达 -10°/+25° 极限后硬停止，继续推杆不再移动
- [x] 手柄摇杆归中后炮塔/炮管不自动回中
- [x] 手柄活跃时显示弹道预测线（炮口出发的抛物线弧线）
- [x] 弹道预测线碰到障碍物（地形/建筑/树木）时在碰撞点截断，不穿透
- [x] 弹道预测线无遮挡时延伸到最大射程自然结束
- [x] 预测线碰撞终点显示小光点标记
- [x] 切换到键鼠输入时弹道预测线自动隐藏
- [x] HUD 操作提示显示为新操作说明
- [x] 双人模式：1P 键盘+鼠标+准星、2P 手柄+预测线 各自正常工作
