🎨 Artifacts — HTML 中间层

这份页面不是"写的网页"，而是 Claude 用 HTML 渲染能力向你传达信息

📊

数据可视化

终端 Markdown 表格最多 4-5 列就溢出。HTML 可以做热力图、甘特图、雷达图——任何 Chart.js/ECharts 能画的。

🎛️

交互式决策

拖动滑块调整参数、点击切换方案、实时预览。终端只能回答不可操作——HTML 既是表达也是操作。

🗺️

架构图 / 流程图

Mermaid 太受限。Canvas/SVG 能做任意图——模块依赖图、调用时序图、类继承图，想怎么画怎么画。

终端 Markdown

  • 纯文本 + 简单表格
  • 无法画图
  • 阅读型 / 静态
  • 屏幕宽度受限
  • 输出即丢弃

Artifacts HTML

  • 任意布局 / 颜色 / 排版
  • SVG / Canvas / 图表
  • 可交互 / 可点击
  • 浏览器全屏查看
  • 文件持久化可回看

⚡ 工作流程（已自动化）

1 你说："对比这三个方案的优劣"
→ 2 Claude 生成 artifacts/comparison.html
→ 3 PostToolUse 钩子检测到 artifacts/ 目录写入
→ 4 2 秒 debounce（批量写入收集）→ 自动打开 Chrome
→ 5 你在浏览器里看到这份页面 🎉
