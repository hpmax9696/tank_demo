炮塔重构实施计划

世界空间 turretYaw · 仅改 engine.js · 约 40 行改动 · 2026-06-21

一、核心思路

把炮塔方向从局部空间搬到世界空间存储。

worldTurretYaw ⟶ 鼠标/摇杆直接驱动 ⟶ 每帧渲染时反算局部 turretYaw

旧：局部空间 + 瞬时稳定器

// 车体右转 → 稳定器瞬时补偿
player.turretYaw += hullDyaw;   // ∞速度
// 鼠标瞄准 → 局部空间追赶
targetYaw = atan2(localDir.x, localDir.z);
player.turretYaw = angleMoveToward(..., 30°/s);
// ⚠ 两条路径在同一个变量上互搏

新：世界空间单一真相源

// 鼠标直接驱动世界方向
worldTargetYaw = atan2(worldDir.x, worldDir.z);
worldTurretYaw = angleMoveToward(..., 30°/s);
// 渲染时自动换算（一条公式同时处理稳定+瞄准）
turretYaw = worldTurretYaw − (π/2 − hullYaw);

四、关键设计决策

  1. 惰性初始化 — worldTurretYaw=undefined，首帧自动算。spawn/respawn 零改动
  2. 局部 turretYaw 变为派生量 — 每帧从世界值算出，不再是持久状态
  3. 归一化集中一处 — 只在推导点归一化 turretYaw 到 [-PI, PI]，worldTurretYaw 允许无界
  4. 只改 engine.js — 敌人/模型/摄像机全部不受影响

五、验证步骤

1. 出生时炮塔指前方，无跳动
2. WASD转车体+鼠标不动 → 炮塔世界静止

4. 摇杆右推 → 匀速旋转不卡
5. 对战模式 P1+P2 → 行为正确
6. 训练重生 → 炮塔重新指前方
7. 狙击模式 → 无异常
