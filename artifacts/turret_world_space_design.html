坦克炮塔世界空间重构

v0.63.02026-06-21状态：待审阅范围：仅 engine.js

一、概述

要解决的问题

当前炮塔系统在车体和鼠标同向转动时感觉迟钝。

根因：三条控制路径在同一个局部空间变量 turretYaw 上互搏。

稳定器
→
turretYaw += hullDyaw  ⚡瞬时，无限速度
鼠标
→
angleMoveToward(turretYaw, localTarget, 30°/s)  🐢限速
摇杆
→
turretYaw += stick * speed * dt  🎮限速

车体右转 + 鼠标同向右转时：稳定器瞬时把 turretYaw 往上冲，但鼠标的 localTarget 反而变小（车体迎向目标），angleMoveToward 以 30°/s 慢速往下拉 → 两者打架 → 炮塔几乎不动 → 感觉迟钝。

解决方案

炮塔像一个陀螺仪平台：车体在它下面自由转动而不影响它；鼠标和摇杆直接在世界空间驱动它。

旧：局部空间 + 瞬时稳定器

// 稳定器（瞬时）
player.turretYaw += hullDyaw;
// 鼠标（局部空间，限速）
localDir = worldDir * inv(hullQuat);
targetYaw = atan2(localDir.x, localDir.z);
turretYaw = angleMoveToward(turretYaw, targetYaw, 30°/s);
// ⚠ 两条路径在同一变量上打架

新：世界空间单一真相源

// 鼠标直接驱动世界方向
worldTargetYaw = atan2(worldDir.x, worldDir.z);
worldTurretYaw = angleMoveToward(worldTurretYaw, worldTargetYaw, 30°/s);
// 渲染时一条公式自动处理稳定
turretYaw = worldTurretYaw - (π/2 - hullYaw);

预期效果

✓ 车体+鼠标同向 → 满 30°/s 灵敏追光标
✓ 车体转鼠标不动 → 炮塔世界静止
✓ 代码更简单（删稳定器 + 删局部转换）
✓ 不影响敌人/六足/摄像机/俯仰

三、新设计

核心状态变量

变量空间性质初始化
worldTurretYaw世界 XZ 平面持久状态，鼠标/摇杆直接修改undefined → 首帧惰性初始化
turretYaw局部（相对车体）每帧派生值，仅用于渲染每帧从 worldTurretYaw 算出

控制路径（改造后）

路径操作
稳定器删除 — 派生公式已隐含稳定效果
鼠标worldTargetYaw = atan2(worldDir.x, worldDir.z)
worldTurretYaw = angleMoveToward(worldTurretYaw, worldTargetYaw, 30°/s)
摇杆worldTurretYaw += stick * speed * dt

核心公式（替代稳定器的唯一一行）

turretPivot.rotation.y = worldTurretYaw − (π/2 − hullYaw)

车体右转 (hullYaw↑) → (π/2−hullYaw)↓ → turretYaw↑ → 炮塔相对车体多转了一份 → 世界指向不变。
稳定效果从"显式补偿代码"变成了"公式的自然结果"。

惰性初始化

// updateAiming / updateAimingForVs 开头
if (player.worldTurretYaw === undefined) {
    player.worldTurretYaw = player.turretYaw + (Math.PI / 2 - hullYaw);
}

createPlayer() 设 worldTurretYaw: undefined，首帧自动对齐车体方向。所有模式/spawn/respawn 零改动。

归一化策略

变量策略
worldTurretYaw允许无界增长（摇杆持续累加），无需归一化
turretYaw（派生值）每帧归一化到 [-π, π]，集中在推导点处理
