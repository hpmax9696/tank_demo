## 二、坐标系约定

| 轴 | 正方向 | 含义 |
|:--:|--------|------|
| X | 正=右 | 坦克左右宽度 |
| Y | 正=上 | 高度 |
| Z | 正=前 | 炮管指向方向（车头） |

- 原点 = 坦克底盘中心，地面 `Y=0`
- Cylinder 默认沿 Y 轴（竖直），需要 `rotation: [π/2,0,0]` 变为水平（沿Z轴）
- 负重轮需要 `rotation: [0,0,π/2]` 变为侧立圆盘（轴线沿X）

## 三、可用几何体类型和格式

```
Box:            size: [宽X, 高Y, 深Z]
TaperedBox:     size: [底宽, 高, 底深, 顶宽, 顶深, X偏移, Z偏移]   ← 7元素！后两个可选(默认0)
TaperedHex:     size: [底宽, 高, 底深, 顶宽, 顶深, X偏移, Z偏移]   ← 7元素！
Cylinder:       size: [半径顶, 高, 半径底]  segments: [圆周分段]
Sphere:         size: [半径]              segments: [经线, 纬线]
Torus:          size: [环半径, 管半径]     segments: [环段, 管段]

每个部件节点可包含:
  name: "名称", type: "类型", size: [...], position: [X,Y,Z],
  rotation: [绕X, 绕Y, 绕Z] 弧度, scale: [X,Y,Z],
  materialId: "材质名", color: "#十六进制"  (color会覆盖materialId颜色),
  flatShading: true/false,
  segments: [...],
  如果是TrackChain: trackParams: {...}
```

**TaperedBox/TaperedHex 的顶面偏移**（size[5], size[6]）：
- `ox`（size[5]）：顶面沿X轴偏移，正=右偏移
- `oz`（size[6]）：顶面沿Z轴偏移，正=前偏移
- 省略时默认0（向后兼容）

## 九、开发工作流

### 标准迭代流程

```
1. 启动预览（先杀残留进程，再起 python http 服务）
2. 打开 http://127.0.0.1:8080/model_factory.html
3. 切换下拉菜单 → 「T-34/85 (v1.6 AI版)」
4. 切换正交视图 📐，看左/前/右/后/顶五视图
5. 按 F12 查看 Console 诊断
6. 发现偏差 → 用 SearchReplace 直接修改 model_factory.html 中的对应参数
7. 刷新浏览器（Ctrl+F5）验证效果
8. 继续迭代，直到满意
```

### 修改文件方式

你直接用 **SearchReplace** 工具编辑 `model_factory.html`，修改 `T34_85_V16_CONFIG` 中对应部件的参数。第 766~874 行。

**不需要**让用户帮你粘贴代码，你自己就能改。

### 修改注意事项

- 所有坐标用绝对值，不要用"下移0.3"这种相对描述
- TaperedBox/TaperedHex 的 size 支持 7 元素：`[底宽, 高, 底深, 顶宽, 顶深, X偏移, Z偏移]`
- Cylinder 默认沿 Y 轴，rotation: [π/2,0,0] 变为 Z 轴水平
- 负重轮 rotation: [0,0,π/2] 变为侧立轮盘
- 调试配色（红轮/蓝链/品红发烟筒）暂时保留，确认结构无误后再删除 color 字段
