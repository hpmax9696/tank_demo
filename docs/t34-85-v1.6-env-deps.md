## 可用几何体清单

### Three.js 内置（6种）

| 类型 | 构造函数 | 参数说明 | three@0.160 行为 |
|------|----------|----------|------------------|
| `Box` | `new THREE.BoxGeometry(w, h, d)` | 宽X、高Y、深Z | 标准长方体，原点在几何中心 |
| `Cylinder` | `new THREE.CylinderGeometry(rTop, rBot, h, seg)` | 顶半径、底半径、高、圆周分段 | 默认8段，Y轴为高度轴 |
| `Sphere` | `new THREE.SphereGeometry(r, wSeg, hSeg)` | 半径、经线段、纬线段 | 球心在原点 |
| `Torus` | `new THREE.TorusGeometry(R, r, rSeg, tSeg)` | 环半径、管半径 | 环面在XY平面 |

### Three.js addons（1种）

| 类型 | 来源 | 参数 |
|------|------|------|
| `RoundedBox` | `three/addons/geometries/RoundedBoxGeometry.js` | `(w, h, d, segments, radius)` |

### 自定义几何体（2种，model_factory.html 内置）

| 类型 | 函数 | size 参数 | 说明 |
|------|------|-----------|------|
| `TaperedBox` | `buildTaperedBox(bw, h, bd, tw, td)` | `[底宽, 高, 底深, 顶宽, 顶深]` | 台型棱柱，底面和顶面为不同大小矩形 |
| `TaperedHex` | `buildTaperedHex(bw, h, bd, tw, td)` | `[底宽, 高, 底深, 顶宽, 顶深]` | 椭圆六棱台，底面和顶面为压扁六边形 |

**TaperedBox 顶点布局**：
```
底面4顶点(y=0)：(-底宽/2, 0, -底深/2) (底宽/2, 0, -底深/2) (底宽/2, 0, 底深/2) (-底宽/2, 0, 底深/2)
顶面4顶点(y=高) ：(-顶宽/2, 高, -顶深/2) (顶宽/2, 高, -顶深/2) (顶宽/2, 高, 顶深/2) (-顶宽/2, 高, 顶深/2)
```

**TaperedHex 顶点布局**（俯视为扁平六边形，前后为尖角）：
```
底面6顶点(y=0)：右(底宽/2,0,0) → 右后(底宽/4,0,底深×√3/2) → 左后(-底宽/4,0,底深×√3/2) → 左(...) → 左前 → 右前
顶面6顶点(y=高)：同上但用顶宽/顶深
```

**关键差异**：TaperedHex 的 "深度" 不是矩形深度。`bd=1` 时，最宽处（左右角）间距为 `1`，前后角间距为 `bd×√3/2 ≈ 0.866`。所以如果想让六边形前后端距离 ≈ 宽度，需设 `bd ≈ bw/0.866 ≈ 1.15*bw`。

## 配置节点字段协议

每个配置节点支持的完整字段：

| 字段 | 类型 | 必需 | 说明 |
|------|------|:----:|------|
| `name` | string | ✅ | 部件名称，用于UI显示和选中 |
| `type` | string | ✅ | 几何类型：Box/Cylinder/Sphere/Torus/TaperedBox/TaperedHex/RoundedBox |
| `size` | number[] | ❌ | 几何体尺寸参数，默认[1,1,1] |
| `position` | number[] | ❌ | 相对父节点的位置[X,Y,Z]，默认[0,0,0] |
| `rotation` | number[] | ❌ | 相对父节点的旋转[绕X,绕Y,绕Z]弧度，默认[0,0,0] |
| `scale` | number[] | ❌ | 缩放，默认[1,1,1] |
| `materialId` | string | ❌ | 材质预设ID，默认'default' |
| `color` | string | ❌ | 自定义颜色(hex如'#4a5c2e')，覆盖materialId的颜色 |
| `segments` | number[] | ❌ | 分段数，默认[8,1]或[8,6]等 |
| `visible` | boolean | ❌ | 可见性，默认true |
| `children` | array | ❌ | 子节点数组，仅Group类型 |

## 材质预设 (MATERIAL_DEFS)

```javascript
{
  steel:       { color:0x6b6b7b, roughness:0.5,  metalness:0.8  },  // 灰钢
  dark_steel:  { color:0x4a4a5a, roughness:0.45, metalness:0.85 },  // 暗钢
  barrel_steel:{ color:0x3a3a44, roughness:0.35, metalness:0.9  },  // 炮管钢（深色）
  rubber:      { color:0x2a2a2e, roughness:0.9,  metalness:0.05 },  // 橡胶/轮胎黑
  camo_green:  { color:0x4a5c2e, roughness:0.75, metalness:0.1  },  // 军绿（车体主色）
  camo_dark:   { color:0x3d4f25, roughness:0.7,  metalness:0.1  },  // 深军绿（炮塔）
  camo_desert: { color:0x8b7d4a, roughness:0.75, metalness:0.1  },  // 沙漠黄
  wood:        { color:0x6b4e3d, roughness:0.85, metalness:0.0  },  // 棕木
  default:     { color:0x888888, roughness:0.6,  metalness:0.2  }   // 灰色默认
}
```

所有材质使用 `THREE.MeshStandardMaterial`，光照使用标准 PBR：
- 1个环境光 (ambient, 0.4)
- 1个方向光 (directional, 0.8, 位置[5,10,7])

## 坐标系速查

```
Y轴 = 上（高度方向）
X轴 = 右（宽度方向）  
Z轴 = 前（深度方向，车头方向）

原点 = 坦克底盘几何中心（履带之间的地面投影点）
```

**炮管方向**：+Z 为前方，炮管沿 +Z 延伸。Cylinder 默认沿 Y 轴，故炮管需 `rotation: [π/2, 0, 0]`（绕X轴转90度放平）。

**旋转约定**：Three.js 使用欧拉角 XYZ 顺序（内旋），单位弧度。
- 绕 X（pitch）：`Math.PI/2` = 90°（将Y轴几何体放平到Z轴）
- 绕 Y（yaw）：`Math.PI` = 180°（车头调转）
- 绕 Z（roll）：通常为0

## 与主游戏(index.html)的差异

| 项目 | model_factory.html | index.html |
|------|-------------------|------------|
| Three.js | 0.160.0 ES Module (CDN) | 0.160.0 UMD (`three.min.js`本地) |
| 光照 | 环境+单方向光 | 环境+方向光+雾 |
| 单位比例 | 1:1 (1单位=1米) | 1:1 |
| 材质 | MeshStandardMaterial | MeshStandardMaterial |
| 模型用途 | 编辑预览 | 游戏内实体 |

> **重要**：模型工厂和主游戏使用**相同的 Three.js 版本和相同的单位系统**。v1.6 模型在模型工厂调好后，可直接导出姿态JSON固化到主游戏中，尺寸行为完全一致。
