### 后弧段修正（P2）

弧段从底(1.5π)绕**前侧**(0)到顶(0.5π)，而非 r16 的绕后侧(π)：

```
旧: angle = 1.5π - d/rR  → 通过 π(后)❌ 绕到Z后方
新: angle = 1.5π + d/rR  → 通过 0(前)✅ Z在±0.30范围内
```
