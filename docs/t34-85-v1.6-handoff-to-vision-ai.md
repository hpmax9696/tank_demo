## 四、🆕 棱台几何体新特性（重要！）

**TaperedBox** 和 **TaperedHex** 的 `size` 数组已从 **5 元素扩展为 7 元素**：

```
旧格式: [底宽, 高, 底深, 顶宽, 顶深]
新格式: [底宽, 高, 底深, 顶宽, 顶深, 顶面X偏移, 顶面Z偏移]
```

**顶面偏移功能**：顶面中心可相对底面中心在 XZ 平面偏移，形成"歪棱台"。例如：

```
上车体: TaperedBox [2.60, 0.5, 6.0, 2.40, 5.8, 0, -1.5]
                                        ↑ 顶面Z向车尾偏移1.5，模拟前高后低的车体
```

### 用法说明
- `ox`（size[5]）：顶面沿X轴偏移，正=右偏移，默认0
- `oz`（size[6]）：顶面沿Z轴偏移，正=前偏移，默认0
- **省略时默认0**（向后兼容现有配置）
- 在模型工厂 GUI 中选择 TaperedBox/TaperedHex 部件后，会在几何体面板中看到「↗ 顶面偏移」子目录

你可以在修改清单中为车体（如上车体）指定偏移值，实现更真实的坦克轮廓。

## 八、坐标系约定

| 轴 | 方向 | 正方向 |
|:--:|------|--------|
| X | 左右 | 正=右 |
| Y | 上下 | 正=上 |
| Z | 前后 | 正=前（炮管指向方向） |

- Cylinder 默认沿 Y 轴，需 `rotation: [π/2, 0, 0]` 转 Z 轴水平
- position 是几何中心，非底部
- TaperedBox size = [底宽, 高, 底深, 顶宽, 顶深, **X偏移**, **Z偏移**]
- TaperedHex size = [底宽, 高, 底深, 顶宽, 顶深, **X偏移**, **Z偏移**]
