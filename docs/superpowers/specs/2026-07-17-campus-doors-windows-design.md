# 校园建筑门窗系统设计

## 范围

5 栋教学楼：综合楼1号、综合楼2号、综合楼3号、教学楼、高年级教学楼。

**排除**：工具房（平房无外廊）、B7 dome（车棚+室内运动场，拱顶无传统门窗）。

## 方案

**方案 A — 贴面薄 Box**：在 ExtrudeGeometry 墙体表面放置薄几何体表示门窗，不修改墙体几何。

## 教室划分

- 教室宽度：`classroomWidth = edgeLen / Math.round(edgeLen / 8)`（约 8u ≈ 10.4m，自动整除边长）
- 例：综合楼1号走廊边 17.7u → 2 间，每间 8.85u

## 走廊面布局（单间教室）

```
| 墙0.4 | 前门0.7 | 墙0.4 |    窗户(~5u, 3-4扇细框)    | 墙0.4 | 后门0.7 | 墙0.4 |
```

- 门高 2.0u，从地板起
- 窗台高 0.8u（≈1m），窗高 1.2u，上沿与门顶齐平
- 窗户分 3-4 扇，扇间细竖框

## 空调面布局

- 窗户位置与走廊面**对称**（同教室、同水平范围）
- 空调外机移到教室门对应外墙位或窗下

## 天桥裁剪

使用与外廊相同的 `skipSegs` 逻辑（`edgeBridgeOverlaps`），只跳过天桥连接子段，不跳过整层。

## 几何体参数

| 元素   | 几何                                  | 颜色         |
| ------ | ------------------------------------- | ------------ |
| 门板   | Box(w=0.7, d=0.04, h=2.0)             | #8B6914 木棕 |
| 窗玻璃 | Box(w=窗宽, d=0.03, h=1.2), posZ=0.8  | #c8ddf0 淡蓝 |
| 窗竖框 | Box(w=0.04, d=0.05, h=1.2)            | #666 深灰    |
| 窗横框 | Box(w=窗宽, d=0.05, h=0.04), 上下各一 | #666 深灰    |

## 新增函数

```javascript
addDoorsAndWindows(parent, ax, az, bx, bz, wallH, type, skipSegs, _stiltY);
```

- `type = 'corridor'`：画前门+窗户+后门
- `type = 'ac'`：只画窗户，返回窗位给空调避让
- 复用 bldGroup 坐标系（rotation.x = -PI/2）

## 空调避让

`addACToEdge` 接收窗户位置列表，空调优先放在门对应外墙位，其次窗下。
