# T-34/85 程序化模型 v1.6 规范 — 给看图 AI 的参考

> 请你基于 T-34/85 坦克的四视图（左侧、正面、顶部、后方），生成一份**用几何体拼装**的程序化模型描述。
> 你不需要写代码，只需描述每个部件的形状、大小、位置、颜色，用下面约定的术语即可。

---

## 一、坐标系约定

```
Y轴 = 上（高度）
X轴 = 左/右（宽度）
Z轴 = 前/后（深度）

原点 = 坦克底盘中心点（车身正中央，履带之间）

车身方向：+Z = 前方（车头方向），-Z = 后方（车尾方向）
```

## 二、可用几何体类型

| 类型 | 参数 `size` | 说明 |
|------|-------------|------|
| `Box` | `[宽X, 高Y, 深Z]` | 标准长方体 |
| `TaperedBox` | `[底宽, 高, 底深, 顶宽, 顶深]` | 台型（顶底矩形不同大小），做倾斜装甲极佳 |
| `TaperedHex` | `[底宽, 高, 底深, 顶宽, 顶深]` | 椭圆六棱台，适合炮塔（俯视椭圆形） |
| `RoundedBox` | `[宽, 高, 深]` + `segments:[段数, 圆角半径]` | 倒角长方体 |
| `Cylinder` | `[底半径, 高, 顶半径]` + `segments:[段数]` | 圆柱/圆台，适合炮管、舱盖 |
| `Sphere` | `[半径]` + `segments:[纬线段, 经线段]` | 球体，适合炮盾 |
| `Torus` | `[环半径, 管半径]` + `segments:[环段, 管段]` | 圆环，适合炮塔座圈 |

每个部件还有：
- `position`: `[X, Y, Z]` — 相对于父节点的位置
- `rotation`: `[绕X, 绕Y, 绕Z]` 弧度（可选，默认0）
- `materialId`: 见下方材质表
- `color`: 自定义颜色（可选，覆盖 materialId 的颜色）

## 五、层级结构模板

请按以下树形结构描述每个部件（用自然语言即可，但需逐项给出尺寸和位置）：

```
坦克根节点
├── 车体 Group (履带以上部分)
│   ├── 下车体 — 最底层车体（倾斜装甲）
│   ├── 上车体 — 上层车体
│   ├── 发动机舱 — 车尾顶部凸起
│   ├── 左履带护板 / 右履带护板
│   └── 尾部排气管等细节
├── 左履带总成 Group
│   ├── 5个负重轮 (Cylinder, materialId: rubber)
│   ├── 主动轮（后方大轮）
│   ├── 诱导轮（前方小轮）
│   ├── 托带轮（履带上沿小轮）
│   └── 履带板（可选，可用 Box 条带简化）
├── 右履带总成 Group（镜像）
└── 炮塔总成 Group（可旋转）
    ├── 炮塔座圈 (Torus)
    ├── 炮塔主体 (TaperedHex) — 俯视六边形/椭圆
    ├── 指挥塔 (Cylinder, 炮塔右后方)
    ├── 舱盖 (Box/Cylinder)
    ├── 炮管总成 Group
    │   ├── 炮盾 (Sphere 或 RoundedBox)
    │   ├── 炮管根部 (Cylinder, 较粗)
    │   ├── 主炮管 (Cylinder, 细长)
    │   └── 制退器 (Cylinder, 炮口略粗)
    └── 车顶机枪（可选）
```

## 六、重点观察事项

请根据四视图特别关注以下 T-34/85 的标志性特征：

1. **车体前装甲倾斜角**：首上装甲约60°倾斜，首下也有倾斜——用 TaperedBox 表现
2. **炮塔形状**：俯视为六边形/椭圆形，前窄后宽，侧面轻微内倾——用 TaperedHex
3. **炮塔位置**：在车体中部偏前（约40%处），非正中央
4. **负重轮布局**：每侧5个大负重轮，前两个间距较大（有间隙），后三个较密
5. **主动轮位置**：在车尾（后方），齿状大轮
6. **诱导轮位置**：在车头（前方），略小于主动轮
7. **发动机舱**：车尾顶部凸起的矩形区域，略高于车体
8. **翼子板**：履带上方的水平护板，宽度覆盖履带
9. **油箱/工具箱**：车尾两侧或后甲板上的外挂附件

## 七、期望输出格式

请为每个部件输出一行描述，包含：部件名称、几何类型、尺寸(宽×高×深，单位米)、位置(X,Y,Z)、材质。

例如：
```
下车体: TaperedBox, 底3.0/底深5.0 → 顶2.6/顶深4.0, 高0.7, 位置(0, 0.35, -0.2), camo_green
炮塔主体: TaperedHex, 底2.0/底深2.4 → 顶1.6/顶深2.0, 高0.7, 位置(0, 1.15, -0.3), camo_dark
主炮管: Cylinder, 半径0.06, 长3.0, 位置(0, 1.5, 1.5), 绕X旋转90°, barrel_steel
负重轮1: Cylinder, 半径0.4, 宽0.12, 位置(-1.4, 0.4, -1.5), rubber
```

**重要**：
- 尺寸单位是米，1:1对应真实世界
- 请尽量参考四视图中的实际比例给出尺寸
- 颜色用 materialId，如果材质表没有合适的颜色，可以额外注明色号
- 位置坐标以部件中心点为准
- 炮管在Z轴正方向（前方）延伸
