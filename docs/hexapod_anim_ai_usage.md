### 步态周期公式

```
gaitPeriod = |turnRate| > 1.0 ? 1.05 / |turnRate|   // 静态转弯: 转速推导
           : |turnRate| > 0   ? 0.72                  // 移动转弯: 固定周期
           : stride > 0.30    ? 0.38                  // 奔跑直行
           :                     0.7                  // 步行直行
```

实装到游戏时, 改为连续钳位: `gaitPeriod = clamp(1.05 / |turnRate|, 0.5, 0.8)`

### CCD 迭代数

```
|turnRate| > 1.0  →  20 + |turnRate| × 13
|turnRate| > 0    →  20 + |turnRate| × 8
stride > 0.30     →  30
else              →  15
damp: 转弯用 0.8, 直行用 0.5
```

### ENGAGE 状态详细设计（v0.55+）

当前 `enemyAI.js` 的 ENGAGE 状态使用履带车辆物理（先转向再前进），不适用于六足战车。六足版应在 ENGAGE 中利用平移动画实现真侧移：

```
┌─────────────────────────────────────────────┐
│ 六足 ENGAGE 行为循环                          │
│                                              │
│  攻击距离内 → 选择绕圈方向(左/右)              │
│  使用 Strafe Turn 横移绕圈                    │
│  + 炮塔/武器独立瞄准玩家                       │
│                                              │
│  可变绕圈半径: 5m~30m                         │
│  turnRate 实时调整:                            │
│    - 大圈(30m): turnRate ≈ 0.15, 慢转        │
│    - 小圈(5m):  turnRate ≈ 0.8,  快转        │
│  gaitPeriod = clamp(1.05/|turnRate|, 0.5, 0.8)│
│                                              │
│  距离 < 理想×0.6 (太近):                      │
│    → Walk Back 后退拉开距离                   │
│                                              │
│  距离 > 理想×1.3 (偏远):                      │
│    → Run Turn 弧线逼近                        │
│                                              │
│  ~2.5s 随机切换绕圈方向                       │
│  每切换方向时 ~30% 概率混合 Walk Back          │
│   制造不规则的 Z 字形规避弹道                   │
└─────────────────────────────────────────────┘
```

### 后退用途

| 动画 | AI 场景 | 战术价值 |
|------|---------|----------|
| Walk Back | ENGAGE 距离过近时后退 | 保持攻击距离，面朝玩家边退边打 |
| Run Back | FLEE 逃跑 / ENGAGE 规避 | 快速脱离危险区域 |
| Walk Back Turn | 后退+微转调整朝向 | 周旋时保持炮口方向 |
